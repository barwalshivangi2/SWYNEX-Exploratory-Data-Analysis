


# SWYNEX Exploratory Data Analysis

This repository contains the Exploratory Data Analysis (EDA) for the SWYNEX internship Task 2. I used Python to analyze the cleaned dataset, calculate statistics, and identify patterns.

## 5 Useful Insights:
1. **Survival Rate:** Overall survival rate was low; the majority of passengers did not survive.
2. **Gender Trend:** Females had a significantly higher survival rate compared to males.
3. **Age Distribution:** The majority of the passengers were young adults between the ages of 20 and 30.
4. **Class Impact:** Passengers in 1st class had a notably higher survival rate compared to those in 3rd class.
5. **Anomalies/Outliers:** Boxplot analysis shows extreme outliers in the 'Fare' column, indicating a few passengers paid exceptionally high ticket prices.
